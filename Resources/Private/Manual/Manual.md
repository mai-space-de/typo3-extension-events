# Handbuch: Veranstaltungen

Termine haben Datum, Ort, Bild, Kategorien und optional einen Link. Serien wiederholen sich täglich, wöchentlich, monatlich oder jährlich, optional bis zu einem Enddatum.

## Kalender

Das Plugin zeigt Monat, Woche oder eine Liste der nächsten Termine. Auf kleinen Bildschirmen bleibt die Listenansicht.

Ohne Link öffnet ein Termin einen Dialog mit Titel, Zeit, Ort und Beschreibung. Ein gesetzter Link führt direkt dorthin. Die Liste lässt sich auf eine Kategorie begrenzen.

## Anmeldungen

Die Anmeldung gilt für einen konkreten Termin der Serie. Eine Maximalzahl und eine Warteliste gelten pro Termin, nicht für die ganze Serie.

Die Bestätigung geht per E-Mail über **Mail**. Teilnehmende kannst du im Backend als CSV exportieren. Zusätzlich lassen sich Termine als iCal-Datei herunterladen.
